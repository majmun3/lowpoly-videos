| Episode | Premise | Video |
|---|---|---|
| 1. [THE LAST EMBER](the-last-ember/) | What if a wandering knight became the final guardian of a dying world? | [`the_last_ember.mp4`](the-last-ember/output/the_last_ember.mp4) |
